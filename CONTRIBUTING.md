# Contributing

Thanks for helping. Keep the project simple: one static page, no build step, no tracking.

1. Fork the repo and create a branch.
2. Make one focused change and test it in light and dark themes and at phone width.
3. Never commit API keys. Keys belong only in the user's browser.
4. Open a pull request that says what changed and why. Add a screenshot for visual changes.

Report bugs and ideas as issues. Be kind in all discussions.

By contributing, you agree your work is released under the MIT license.
