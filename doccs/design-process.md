# Design process

1. **Define the job.** Check global prices and popular trades in seconds, with no sign-up.
2. **Choose storage.** Saved stocks and the API key stay in the browser. No account, no server data.
3. **Map the screens.** Markets, Stocks, Popular trades, My dashboard, Live data, Design files.
4. **Sketch wireframes.** See `wireframes.md`. One header and one star action on every screen.
5. **Set tokens.** See `design-tokens.md`. Green and red are paired with arrows so colour is never the only signal.
6. **Be honest about data.** A banner always says whether numbers are sample or live.
7. **Test.** Phone width, keyboard focus, light and dark themes.
8. **Open source.** MIT license, bring-your-own-key so there is no shared secret to protect.
